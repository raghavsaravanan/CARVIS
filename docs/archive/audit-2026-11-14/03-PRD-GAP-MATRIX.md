# Provisional PRD gap matrix

## Important limitation

`docs/PRD.md`, named as the primary requirements source, is missing from the repository and from `HEAD`. The rows below derive from the eight explicit launch outcomes and nonfunctional constraints in the audit brief. IDs prefixed `BRIEF-` are audit-created placeholders and must be replaced with the approved PRD's real IDs before implementation is authorized.

Status vocabulary is exactly: **IMPLEMENTED AND VALIDATED**, **IMPLEMENTED BUT NOT VALIDATED**, **PARTIALLY IMPLEMENTED**, **MISSING**, **DEFERRED**, **UNNECESSARY FOR V1**.

## Validation taxonomy

- **Deterministic local:** backend unit/integration-style tests with fakes/local Qdrant; pure Swift executable checks.
- **Mocked provider:** Nemotron/OpenAI client, Vapi payload/config, Qdrant behaviors.
- **Historical live:** prior docs describe cloud Qdrant, LlamaParse and physical camera checks; not rerun in this audit.
- **Not validated:** phone-first audio, auth, durable history, TestFlight archive, production multi-tenancy, licensed data, real pilot workflow.
