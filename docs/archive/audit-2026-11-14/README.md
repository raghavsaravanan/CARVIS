# Historical repository audit

The numbered files in this directory record the repository audit completed on 2026-11-14
against commit `39b9a7f`, before repository consolidation.

The audit initially ran while `docs/PRD.md` was absent, so its `BRIEF-*` requirement IDs and
P0 percentage are provisional historical estimates. The subsequently supplied
[`../PRD.md`](../../PRD.md) is now the product source of truth and takes precedence.

The audit intentionally describes components that existed at that time, including the retired
React frontend and duplicated configuration. Use [`../backend/architecture.md`](../../backend/architecture.md),
the root [`../../README.md`](../../../README.md), and
[`../REPOSITORY-CONSOLIDATION.md`](../REPOSITORY-CONSOLIDATION.md) for the current repository.

The detailed audit remains available because it contains evidence, safety findings, retention
decisions, architecture rationale, and implementation risks that should not be erased merely to
reduce documentation count.
